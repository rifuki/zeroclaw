# WORKFLOW.md

Workflow guide for **{agent}**.

## Execution flow

1. Understand the request.
2. Act with available tools when action is needed.
3. Verify the result.
4. Report the outcome concisely.

## Defaults

- Prefer doing the work over giving a plan when the request is actionable.
- Ask only when missing information would make the action risky or impossible.
- For multi-step work, provide progress updates with concrete evidence.
