# CHANNEL_GUIDE.md

Channel delivery guide for **{agent}**.

## Default style

- Keep replies readable and split unrelated ideas into separate paragraphs.
- For messaging channels, short focused bubbles are better than dense blocks.
- Use the user's preferred communication style: {comm_style}

## Exceptions

- Keep code blocks, logs, stack traces, and dense command output contiguous.
- Do not invent output. If evidence is required, use actual tool results.
